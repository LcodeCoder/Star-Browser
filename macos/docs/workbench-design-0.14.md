# 环境编辑体验与公开实现研究

本轮目标：减少创建和编辑环境时的滚动、误配置和修改丢失。参考用户指定的 Simprint：研究其连续环境列表、创建页分区导航和配置摘要，独立实现适合 Star 的交互。不直接移植其 AGPL 代码，也不把配置项数量当作内核能力的证明。

颜色延续现有工作台：云灰 #F2F4F7、工作面 #FFFFFF、石墨 #28313D、辅助字 #59677C、航蓝 #3C5BC0；夜间沿用用户要求的深蓝工作面 #222F45。结构依靠分区、对齐和状态文字，不增加装饰卡片。

字体沿用宿主系统，正文 13px，说明与摘要至少 12px，主要标题 18px。代理地址和内核版本可用等宽字，说明用普通正文。

宽窗采用固定标题、可滚动分区导航、独立滚动编辑区、配置摘要及固定保存区。正文左对齐；摘要展示系统、地区、网络、语言、时区和覆盖策略。窄窗摘要可折叠，编辑区占主要高度。键盘通过分区入口定位，并保留焦点与减少动画偏好。

```text
编辑环境                                  关闭
基本信息  网络连接  语言时区  扩展  指纹权限
┌ 连续表单，独立滚动         ┬ 配置摘要         ┐
│ 名称 / 地区 / 起始页        │ 当前选择         │
│ 网络与配置                 │ 生效条件与差异   │
└                            ┴                  ┘
具体校验错误                  取消 / 保存更改
```

设计复核：保留 Star 的星形标记与深蓝主题，借鉴 Simprint 的信息组织；不增加泛化仪表盘或重复统计。摘要只展示用户已配置值，自动设置只说明解析来源，不编造未启动时的真实网络出口或随机硬件结果。

实施验收：保存前用与主进程一致的规则校验，错误关联并定位字段；代理信息不完整时不可静默丢弃；未保存修改关闭前可继续编辑或放弃；保存期间阻止重复操作。使用真实 Electron 的宽窄窗口、浅深主题、键盘、屏幕阅读语义、焦点返回和原有专项测试验证。


## 已落地的交互闭环

环境、代理、任务与工作台书签编辑都支持具体字段错误、未保存保护、失败保留草稿、保存时禁用关闭，以及整个对话框范围内的 Cmd/Ctrl+Enter。共享字段组件把标签与说明分开，说明/error 通过 aria-describedby 关联，屏幕阅读名称保持简洁。

启动状态展示真正执行的配置、网络、内核与界面阶段，失败显示明确原因和重试入口；窗口完成界面握手才标为就绪，点击多次不会创建重复进程。

浏览器星标编辑沿用相同标题/网址校验，提供真实标签、字段错误、草稿保护、保存/删除失败恢复、忙碌状态和焦点返回。过长网页标题仅自动截取生成的书签名称，手动输入仍严格校验。气泡在窗口缩放时重新定位，浅深主题与窄窗口保持可操作。

验证使用临时数据和本地页面，逐项保存实际结果与截图；不展示虚构的通过率或内核能力。CreepJS 仍观测到必要 JS fallback 差异，报告直接保留实际结果。
