## 可以使用的能力

- Star 星形品牌与 Google 风格中性底色/蓝色强调，浅深主题；环境列表、主从详情、搜索过滤、分组标签、置顶、批量操作、命令定位与窄窗返回。
- 独立持久分区与本机 Chrome 环境；环境复制/导入使用独立身份，原浏览数据受到保护。环境归档、删除配置、备份恢复和文件操作有明确范围。
- HTTP、HTTPS、SOCKS5 代理配置和代理库，真实连通/出口检查与失败阻断；当前已实测 HTTP、HTTP 鉴权、SOCKS5 鉴权，本地地理模拟与真实转发明确区分。
- UA/Client Hints、语言、原生时区、屏幕和 DPR、硬件配置与可控指纹策略；网页首脚本、Dedicated Worker 与 CSS 对照检查；本机 Chrome 多网页选择检查。
- 标签固定/排序/静音/复制、关闭恢复、会话恢复、后台休眠和实际 guest 释放；输入、离开确认、媒体、下载、任务和同步保护。
- 书签、独立历史、页内查找、缩放、下载暂停/继续/取消、网站权限、扩展库及各环境隔离；Cookie 和网页存储加密备份与独立恢复。
- 本地 API、内置浏览器主控/跟随同步、本地串行任务、取消/失败/中断反馈、真实 PNG 截图、任务定义选定导出/导入预览。
- 本轮浏览器设置完整回填、代理草稿预览、明确保存、错误重试、保护锁和新网页首脚本立即生效，支持浅深主题、固定操作栏、键盘关闭与返回焦点。
