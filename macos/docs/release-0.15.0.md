# Star Browser 0.15.0

## 这次交付

浏览器和工作台按用户指定的 Simprint 清爽方向重新调整：白色内容、浅灰背景、细分隔线、蓝色操作，以及中性深灰主题。学习固定提交 d2dc939bfae8efda8e4e4d791587d7a364ca4dd8 的配色和层级，界面在 Star 中独立实现。两处共享 palette.css，设计与复核见 [设计记录](browser-design-0.15.md)。

- 浏览器顶部采用紧凑标签行和独立导航行，环境身份位于右侧，地址输入保留主要宽度。
- Mac 浏览窗口使用原生嵌入式窗控，顶栏可拖动，标签和按钮保持正常操作。
- 新标签页提供简洁搜索、常用网址、收藏与最近访问，备用离线起始页也使用同一配色。
- 常用网址使用原生按钮，支持 Enter/Space，在当前环境内导航并保留会话；不再跳到系统默认浏览器。
- 环境身份按钮可编辑设置，关闭、取消和保存后返回实际触发按钮；失败及未保存修改保留草稿。
- 回到起始页时更新标签和窗口标题，清除旧页面加载与失败提示。
- 调整浅深主题、640px 窄窗、键盘焦点、减少动画和 Windows 快捷键文案。
- README 增加本轮实际界面截图与设计记录。

## 安装包

使用 npm run build:mac 和 npm run build:win 构建 Mac arm64 DMG/ZIP 与 Windows x64 EXE/ZIP，再用 npm run verify:artifacts 检查架构、版本、完整性和全部 src/ 资源匹配。Mac arm64 打包应用实际启动完成 13 项烟测，另有 12 项界面体验检查及 6 项新标签页专项检查通过。四个发行文件均通过架构、版本、完整性和全部 src/ 资源匹配检查，校验清单为 SHA256SUMS-0.15.0.txt。产物保存在 macos/dist/，本版本尚未发布到 GitHub Release。

macOS 当前使用 ad hoc 签名，未进行 Developer ID 签名或公证；Windows 安装程序未签名。Windows 交叉构建与格式校验不替代目标 Windows 系统中的安装和运行验收。

## 指纹与内核剩余条件

本版本没有把界面改进计为内核反检测能力。严格上下文回归保留内置浏览器跨源 iframe 的原生 DPR/CSS 差异，结果为部分通过。

定制 Chromium 小范围补丁及独立策略测试已准备，但本机缺少完整 Xcode、GN/autoninja/gclient、完整 Chromium checkout 和依赖，尚未完成完整内核编译及实际运行验收。内核 P0 仍未完成；不以补丁准备或 JS 读值测试宣称任意网站不可检测。
