# Star Browser 0.13 体验修订

用户任务是找到环境、继续工作、配置网络、理解失败并恢复。截图暴露的文本框高度和空结果比例不作为“个人偏好”处理：可读、可操作、可恢复是产品底线。

色彩：浅色使用云灰 #F2F4F7、白 #FFFFFF、石墨 #28313D、辅助字 #59677C、航蓝 #3C5BC0。深色使用石板 #20242B、工作面 #282D35、输入面 #303640、正文 #D8DCE4、辅助字 #ACB7C7；浅蓝 #AFBFFF 用于链接和焦点，实体蓝 #4B63B6 用于主要按钮。文本色和按钮底色分开，避免亮色按钮与白色正文形成刺眼的大块区域。状态色有相应低亮度底色。

字体：沿用宿主系统字体，不为视觉风格增加远程字体。正文 13px/1.6，辅助内容至少 12px；标题 18–24px，表格 12px。代理地址使用等宽字只限数据输入与地址列。

布局：浏览器标签在左方连续排列，＋紧邻标签末尾，搜索标签在右方；标签过多才压缩并横向滚动。批量检测围绕“输入 → 检测 → 修复失败”连续分区：可读多行输入、完整进度、结果搜索/筛选、按需导出。表格允许水平滚动，不能把九列硬挤进窄窗口。标题/关闭及底部操作始终可达。

动效：系统滚轮/触控板由浏览器原生处理，不劫持 wheel；定位跳转与横向标签定位采用平滑滚动。弹层和页面以短透明度/轻位移动效维持空间连续性，操作反馈不挪动按钮。减少动态效果时关闭平滑滚动和过渡。

设计复核：不引入 KPI 卡墙、光效、背景粒子或卡片套卡片。可辨识度放在浏览器连续标签、环境标识与工作面上。删除旧 HTML 的蓝白覆盖规则，结构与语义主题分离；批量检测复用统一组件语义，避免再次被单行输入样式压缩。

验收：真实 Electron 宽/窄、浅/深、减少动画、键盘、焦点返回、空输入、部分结果、错误、停止、筛选、重开、导出，以及 30+ 标签溢出。未在 Windows 真机运行的结果不能写为已验收。
