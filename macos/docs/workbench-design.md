# Star Browser 0.12 工作台

用户任务：定位环境 → 继续浏览 → 就地调整 → 检查当前网页。列表保留上下文，详情以侧栏展开；窄窗口的详情提供明确返回操作。工具页围绕真实对象、筛选和操作组织，不增加汇总卡墙。

色彩：雾白 #F5F6F8、石墨 #232833、星蓝 #465CE8、深夜 #171A21、成功绿 #237A57、错误红 #C43D4B。浅深主题共享语义变量，强调色用于当前选择、焦点和主要动作。

字体：系统 UI 字体（macOS SF/PingFang、Windows Segoe UI/Microsoft YaHei），正文 13px/1.5、辅助 12px、页面标题 24px/1.25、数字采用等宽数字。常规控件 34px；8px 间距基准，分区靠留白与分隔线。

布局：可收起侧栏 | 页面标题与主动作 | 搜索/筛选 | 对象列表 | 选中对象详情。顶部展示工作位置，底部展示本地状态；浏览器工具栏始终保留后退、前进、停止/刷新和地址输入。

组件：沿用 Radix Dialog/DropdownMenu/Tabs 和 cmdk，适配 shadcn/ui 的侧栏折叠、命令搜索及受控详情模式。轻量反馈只改变透明度/颜色，避免内容位移，尊重 reduced-motion。

评审：避免增加新的平行导航；跨平台文案不写死 Mac；数据错误保留上下文与重试；离线仍允许本地管理；加载、开发者工具必须作用于当前标签；空状态给出下一步；全部操作须通过运行中的 Electron 页面验证。
