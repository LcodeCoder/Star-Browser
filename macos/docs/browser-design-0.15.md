# 浏览器与工作台视觉调整 0.15

用户要求以 Simprint 的清爽样式重新设计浏览器。参考固定提交 d2dc939bfae8efda8e4e4d791587d7a364ca4dd8 的配色和信息层级，在 Star 独立实现。

## 设计计划

白色内容面 #ffffff，浅灰底 #f7f8fa，正文 #20252d，次要文字 #626b79，分隔线 #e5e8ed，操作蓝 #2563eb。深色使用中性灰。浏览器和工作台共享 palette.css。字体使用系统 UI 字体和 PingFang SC，普通界面 13px、标签 12px、起始页标题 24px。

```text
[系统窗控 / Star] [标签] [+]                  [当前环境] [标签搜索]
[后退 前进 刷新 起始页] [网址与收藏] [收藏 历史 设置 更多]
[书签列表]
[网页 / 简洁起始页]
```

标签、导航和环境信息分开；地址栏占据主要宽度。新标签页用搜索与紧凑站点列表，收藏和历史按两列排列。Mac 使用原生嵌入式窗口控件，窗口顶栏可拖动，按钮和标签可以正常交互。

## 设计复核

保留 Star 标记，减少不必要的图标与强色背景。批量代理检测从菜单可达；快捷启动保留明确入口。浅深主题、窄窗、键盘焦点、未保存保护和真实环境信息均保留。地址图标只表示网址输入，不冒用未经验证的安全连接标记。

验收以真实 Electron 窗口、浅深主题、导航、菜单、起始页、设置和书签专项检查为准。Chromium 的编译与原生运行验收保持独立记录。

## 交互验收

新标签页 8 项实际检查覆盖浅深主题、1280/780/640px 窗口、正文对比度、默认常用网址、键盘导航与当前环境会话。常用网址改成原生按钮，并在当前环境导航；首脚本保持已配置的语言和时区，Cookie/localStorage 保留。

收藏异步读取完成后同步更新可见的新标签页。回归检查故意延迟首次 IPC 读取，确认收藏会从空状态自动出现；矮窗口同时验证设置分区的 Enter/Space 与鼠标展开收起。设置表单自动滚动立即定位，避免焦点字段仍在移动。

当前环境身份按钮和工具栏设置入口共享对话框。关闭、取消或保存时返回实际触发按钮；验证失败和未保存退出保持草稿。回到起始页更新标签和窗口标题，并清除旧页面的加载/失败提示。备用离线起始页也使用共享配色。快捷键提示按 Mac/Windows 显示。
