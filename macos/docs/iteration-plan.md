## 设计计划

用户首先需要找到要工作的环境，确认网络与配置，启动或切回浏览器。主要工作流采用环境列表与相邻详情；批量选择后工具栏就地替换，浏览器持续显示环境身份与代理状态。首屏不编造环境或指标。

颜色：背景 #f6f8fc；内容 #ffffff；文字 #202124；品牌 #1a73e8；成功 #188038；警示 #b06000；错误 #c5221f。深色采用 #17191d/#202329 与 #8ab4f8，状态颜色保持相同含义。
字体：macOS 的 SF Pro / PingFang SC 承担高频阅读，数值使用 tabular-nums，标题 25px，正文 13px，辅助信息 12px。Google 风格的清爽可读性用于交互，Star 的四角星与细轨道作为唯一鲜明品牌记忆。
布局：固定左侧导航；连续顶部标题/操作/搜索过滤；主列表；可关闭的右侧详情。小窗口详情独立显示且提供返回。避免 KPI 卡墙与嵌套卡片。
组件：按 shadcn/ui 的 Radix 组合使用 Dialog、Dropdown Menu、Tabs 和 cmdk，改为 Star 的紧凑样式。轻量 120–160ms 动效只用于触发后的反馈；支持减少动画。
评审：不采用营销大标题、渐变卡片和无用指标；真实的环境标记、状态和配置就是视觉内容。

## 当前实现顺序

1. Star 品牌、logo、工作台结构与真实空状态。
2. 环境详情、搜索/分组/标签/排序/置顶、批量启动停止、复制、归档恢复、导入导出。
3. 代理库、批量录入、检测与失败阻断，避免代理故障回退直连。
4. 指纹与内核版本一致性、手动硬件设置、权限与 TLS 验证。
5. 浏览器主题、标签搜索与恢复、历史、下载、查找、缩放、书签。
6. 自动化与本地 API、任务执行与审计；外部依赖明确登记。
7. 大数据列表、启动延迟、后台资源、真实界面测试与打包回归。

每轮只记录已实际实现和已验证的结果，下一轮优先修复失败和闭环缺口。


扩展设计：扩展库采用连续对象列表，名称/版本与真实分配数量就地显示；权限在行内展开。添加目录先预览，再存入本地库，环境编辑中按需勾选。浅深主题沿用现有 token，不新增装饰色。配置错误与内核兼容问题给出具体加载失败原因。


本地 API 设计：设置页提供真实服务状态、地址、端口和密钥操作，默认关闭。使用已有连续设置分区，不新增监控指标。接口说明通过就地对话框查看/复制，端口冲突提供可操作错误；开启与停止复用工作台的真实环境逻辑。


备份设计：设置页采用连续“备份与恢复”分区。保存时选择已停止环境与密码；恢复先展示环境、日期、Cookie 数量及扩展，再确认生成独立副本。进度与可修复错误就地反馈，工作中禁用关闭。备份保留原指纹种子用于恢复同一身份，配置复制依然生成新种子。


同步设计：连续环境列表里选择一个主控与最多九个跟随；仅选择已就绪内置浏览器。开启后显示主控、跟随、暂停/停止与排列窗口，就地错误。各浏览器顶部提供身份提示和立即停止。输入只从主控当前网页转发到所选环境，不存储输入内容；系统输入法、文件和系统对话框保留各自操作边界。


任务设计：本地任务采用连续定义列表与执行记录，按步骤展示当前进度、耗时、错误与截图；编辑器在同一对话框完成添加、排序与删除。选择 1–50 个环境后串行执行，待执行总量最多 100；运行时保护环境，取消及时停止后续步骤。应用退出标记中断，不自动重复网页操作。任务定义保存在本机，执行记录不保存填入文本。


配置检查设计：环境指纹详情保留当前配置，增加就地“检查当前网页”。只读取当前环境已打开的网页，以网页/Worker/CSS 上下文显示真实值、配置与差异；加载和检查失败可重试，不提供虚构分数。高级编辑增加屏幕宽高与 Canvas/音频/WebGL/页面几何策略，默认几何保留原生布局。
