📖 Star Browser · 使用教程

专为外贸人提供的免费指纹浏览器：每个环境 = 独立指纹 + 独立代理 + 独立 Cookie。这篇图文教程帮你 5 分钟上手。

1什么是Star Browser（指纹浏览器）

普通浏览器所有账号共用同一套「设备指纹」（系统、时区、语言、UA、屏幕等）。平台用指纹关联账号，一旦一个号出事，其它号也容易连坐。

Star Browser把控制台和内核浏览器分开：你在控制台创建「环境」，每个环境都生成一套全新的伪装指纹，再注入到独立的内核窗口里运行。多个环境之间彼此隔离，互不相认。

💡 一个环境 ≈ 一台「干净的新电脑 + 新网络」。多账号矩阵运营时，给每个账号单独开一个环境最稳妥。

2三步创建第一个环境

  • 新建：点左上角「+ 新建环境」，取个名字、选个分组。
  • 配置：选操作系统（Windows / macOS / Android）与目标国家，按需填代理（支持 SOCKS5 / HTTP，也能一键粘贴 host:port:user:pass）。
  • 打开：在环境列表点「在内核中打开」，几秒后内核窗口就绪，可直接上网。
💡 不填代理也能用（走本机出口）。但做多账号时务必每个环境配独立代理，否则指纹隔离失去意义。

3指纹与时区自动对齐（为什么 whoer 不报时差）

很多指纹浏览器「时区」是个写死的默认值，和代理出口 IP 的真实地理对不上，检测网站（whoer / browserscan）一比对就报「时区不一致」。

Star Browser在打开环境的瞬间自动解析出口 IP 的真实地理，把时区、语言对齐到真实出口（有代理走代理出口，无代理走本机出口），再注入内核。所以检测网站看到的时间、语言和 IP 地理是吻合的。

💡 想要完全手动？在环境编辑里把「浏览器语言 / 时区」设为具体值即可锁定，关闭「自动跟随出口 IP」。

4内置社媒 & 检测网站快捷入口

内核窗口右上角是社媒启动台，点一下在新标签打开常用平台；下方还有「检测类网站」分组，专门用来验证指纹是否过关：

whoer.com综合指纹 / IP 检测
browserscan.net高级指纹体检
browserleaks.comWebRTC / Canvas 泄露
iphey.com一键判定是否暴露
dnsleaktest.comDNS 是否泄漏
whatismybrowser环境信息总览
💡 打开环境后，先点开 whoer / browserscan 跑一遍——时区、语言、IP 地理三处都绿，基本就稳了。

5代理管理 & Cookie 管理

代理管理左侧「代理管理」汇总所有环境的代理，一键检测出口 IP / 国家 / 时区，相同代理自动归并，绿/红标签一目了然。
Cookie 管理左侧「Cookie 管理」按环境查看 Cookie 条数，支持导出 / 导入 / 清空，各环境完全隔离。

运营社媒矩阵时，把账号的登录态（Cookie）按环境备份好，换机或重装后一键导入即可恢复，不用每次重新登录。

6常见问题（FAQ）

  • 窗口加载慢？首次打开会联网对齐指纹（已加 10 分钟缓存），重复打开是秒开；直连无代理也正常。
  • 打不开网页？先检查代理是否填对、出口是否通——在环境编辑点「检测代理」看出口 IP；带账号密码的 SOCKS5 会自动走本地无鉴权网关。
  • 指纹与 IP 时区不一致？环境编辑里「浏览器语言 / 时区」可手动锁定（默认自动跟随出口 IP）；也可在控制台点「检测代理」确认出口地理。
  • 想用本机 Chrome 打开？环境「更多」里选「本机 Chrome」也能带同样指纹启动，适合需要本地扩展的场景。
